## Recommended repository settings

- Keep the repository **private** until [the release checklist](PUBLIC_RELEASE_CHECKLIST.md)
  has passed, especially scanning the full Git history and reviewing author emails.
- Enable issues and private vulnerability reporting, or provide a verified private
  channel for security reports.
- Enable Dependabot alerts, code scanning where supported, and branch protection.
- Do not advertise `v0.2.x` until that implementation is present in the remote
  repository, tested, and the version is updated.
- Do not claim native Grok Bot chat deletion, compaction, or measured billing savings.

## Short social description

**Grok Context Manager (GCM)** is an open-source, local-first toolkit that
helps people preserve important AI-agent context. Import conversation text,
review checkpoints, archive history, and prepare concise handoffs. It does
not alter Cursor Grok Bot's internal chat history or promise usage savings.

## Suggested first release label

`v0.1.0-beta` — only after the exact checked-in commit is validated and
the repository passes the complete release gate. Avoid creating a GitHub
release or visibility change before then.
