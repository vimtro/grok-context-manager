# Testing

## Commands

```powershell
pnpm install
pnpm typecheck        # tsc --noEmit over all packages, apps and tests
pnpm lint             # ESLint (typescript-eslint)
pnpm format:check     # Prettier
pnpm build            # Vite dashboard + esbuild CLI bundle (required before CLI and e2e tests)
pnpm test             # Vitest: core, storage/service, MCP, packaged CLI
pnpm test:e2e         # Playwright against the built dashboard (desktop + phone viewport)
pnpm smoke            # pack the CLI, npm install -g into a temp prefix, run the workflow
```

First Playwright run: `pnpm exec playwright install chromium` (CI uses `--with-deps` on Linux).
