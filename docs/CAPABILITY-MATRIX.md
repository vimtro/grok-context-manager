# Grok Bot capability matrix

Checked **2026-10-19**. GCM shows the same matrix in `grokcm capabilities`, the dashboard Settings page and the
`gcm_describe_capabilities` MCP tool (`packages/core/src/capabilities.ts`).

Statuses: **VERIFIED_SUPPORTED** (documented or confirmed by Cursor staff), **VERIFIED_UNSUPPORTED** (documented as
absent or confirmed missing), **EXPERIMENTAL** (reported by staff/third parties but undocumented or unconfirmed),
**UNKNOWN** (no reliable evidence).

These products are different and are **not** what GCM integrates with: Cursor IDE agents, Cursor Cloud Agents
(`api.cursor.com/v1/agents`), and xAI API–based Grok applications. GCM targets Cursor's **Grok Bot** desktop/cloud
teammate product.

## Conflicts noted

- **"New chat" wording.** D2 shows "New chat (the + button) or Cmd+N" — but it leads to _Create new Bot_ or a group
  chat, not a fresh 1:1 conversation with an existing bot. F1 confirms no same-bot fresh session. GCM relies on the
  group-chat route and labels its effect unverified.
- **Reset chat.** Staff describe it; a Windows build did not show it; the official docs do not mention it. GCM treats
  it as optional, destructive and user-performed.
- **Token usage.** Users report very large per-reply input; staff called the reported token usage "not intended
  behavior" (Aug 26, 2026). GCM never claims platform savings without user measurements.
