# Changelog

All notable released changes to Grok Context Manager should be documented here.

## [Unreleased]

- Repository presentation refresh, FAQ, roadmap, and GitHub About guidance.
- Community issue templates, vulnerability disclosure policy, and public-release
  safety checklist.

Documentation-only work does not change application behavior or version numbers.

## [0.1.0] — Initial GitHub baseline

- Local-first CLI and dashboard for imported agent conversations.
- Reviewable context analysis, checkpoint versions, archive search, and handoffs.
- MCP server and reusable Grok Bot skill.
- Synthetic examples and automated tests.
- Windows-first setup instructions.

**Caveat:** The shorter text produced by GCM is not evidence of a lower
Cursor Grok Bot bill. The platform's native history cannot be edited through
GCM's supported integration surfaces.

See [README](README.md) for the current checked-in code and limitations.
