# Community Code of Conduct

We want Grok Context Manager to be a welcoming, technically rigorous project for people from varied backgrounds and skill levels.

## Expected behavior

- Communicate respectfully, even when disagreeing.
- Critique ideas, code, or evidence—not people.
- Share reproducible results and label speculation clearly.
- Protect confidential bot transcripts, tokens, contact information, and account details.
- Welcome good-faith questions and contributions.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, unwanted sexual attention, and publishing private data or credentials are not tolerated.

## Scope and enforcement

These expectations apply to repository issues, pull requests, discussions, reviews, and other project-managed spaces. Maintainers may edit or remove harmful content, close discussions, or restrict participation based on severity.

To report a conduct problem, contact repository maintainers privately. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

This policy is a concise project policy, not an endorsement or affiliation with Cursor or xAI.
