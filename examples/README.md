# Examples

| Folder           | Contents                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `conversations/` | Inputs. `sales-bot.txt` (short, hand-written: rules, an approved proposal, a superseded decision, a fact update, a conflict, a secret, an injection attempt). `research-bot.json` (JSON message list with content parts). `chief-of-staff-long.md` (synthetic 22-day transcript generated by `scripts/generate-long-fixture.mjs`, ~16k estimated tokens, with planted facts). |
| `bot-profiles/`  | Profile JSON for `grokcm bots add <id> --from-file …`.                                                                                                                                                                                                                                                                                                                        |
| `checkpoints/`   | Generated checkpoints (Markdown for reading, JSON re-importable with `grokcm checkpoint import`).                                                                                                                                                                                                                                                                             |
| `handoffs/`      | Generated handoff prompts — what you paste into the new Grok Bot conversation.                                                                                                                                                                                                                                                                                                |

All conversations are fictional. Regenerate the outputs with `pnpm build && pnpm examples`.

Try it:

```powershell
grokcm bots add sales --from-file examples\bot-profiles\sales.json
grokcm import examples\conversations\sales-bot.txt --bot sales
grokcm analyze --bot sales --show-items
```
